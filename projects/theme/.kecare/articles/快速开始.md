# 快速开始

欢迎使用 Kecare，使用Kecare相当之简单，本文档将帮助您快速上手。 如果您在使用过程中遇到问题，请在[Github](https://github.com/Pamperkyumi/kecare/issues)上提问。

在使用 Kecare 之前，你需要先安装下列应用程序

- Node.js - v22 或更高版本
- 文本编辑器 - 比如 Vscode
- Bun -  推荐喵

## 通过CLI安装

你可以在机器上的任何位置运行 `create kecare` ，因此开始之前无需为项目创建新的空目录。如果你还没有为新项目准备空目录，向导会自动帮你创建一个

::: tabs

@tab bun

```js
bun create kecare@beta
```

@tab npm

```ts
npm create kecare@beta
```

:::

如果一切顺利，你将会看到如下类似的消息。并且建议你使用Kecare提供的模板来使用Kecare。

![安装向导](http://pichostoss.oss-cn-shanghai.aliyuncs.com/images/1785680820894.png)

现在你的项目已经创建完成，你可以 `cd` 进入新的项目目录，开始使用 Kecare。

安装依赖

::: tabs

@tab bun

```js
bun install
```

@tab npm

```ts
npm install
```

:::

生成文章数据

`kecare gen .`

启动本地服务器

::: tabs

@tab bun

```js
bun run dev
```

@tab npm

```ts
npm run dev
```

:::

如果一切顺利，你也将会看到如下类似的消息

![启动服务器](http://pichostoss.oss-cn-shanghai.aliyuncs.com/images/1785681846899.png)

按住Crtl点击图中的Local连接就可以在本地浏览器中预览你的网站了。

接下来你就可以开始学习Kecare的项目结构以及如何编写文章以及主题了。
